KP USB Wi-Fi Logs - 인터넷 없이 설치

Korea Projection 1.7.4.2를 먼저 설치한 뒤 사용합니다.
이미 KP USB Wi-Fi Logs 1.7.4.2가 설치돼 있으면 이 과정은 생략합니다.

1. 이 폴더 안 NEMESIS.data, packages 폴더, KP_USB_EXPORT.txt를
   USB 최상위에 복사합니다. 이 폴더 자체를 USB 최상위로 복사하는 방식이 아닙니다.
   기존 USB를 사용한다면 같은 이름의 파일만 덮어씁니다.
2. 차에 USB를 다시 꽂고 Logs 설치/업데이트 확인 창에서 '예'를 누릅니다.
   Package Store를 열지 않으므로 인터넷 연결이 필요하지 않습니다.
3. 설치 후 NEMESIS → My Packages → KP USB Wi-Fi Logs에서 실행합니다.
   USB의 KP_USB_EXPORT.txt는 나중에 기록을 복사할 때도 필요하므로 유지합니다.

차량에는 NEMESIS, HMG-API와 KP 1.7.4.2가 이미 설치돼 있어야 합니다.
메인 KP 설치용으로 되돌릴 때는 바깥 폴더의 NEMESIS.data를 USB 최상위에
다시 복사하면 됩니다. 두 설치 모두 USB 안 ZIP 파일을 직접 사용합니다.
